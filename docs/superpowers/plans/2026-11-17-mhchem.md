# Chemistry in TeX Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read mhchem `\ce{…}` and `\pu{…}` into ordinary math nodes, add prescripts to the tree, and make the TeX writer write back the source of constructs it reads but does not draw.

**Architecture:** A source wrapper node carries the TeX of `\ce`, `\pu`, `\boxed` and friends; every writer but TeX sees through it. `Scripts` gains optional prescripts. A separate chemistry parser turns a `\ce`/`\pu` argument into identifiers, numbers, scripts, operators and stretchy arrows, handing `$…$` and commands back to the TeX reader.

**Tech Stack:** PHP 8.4, PHPUnit, the `quoin/math` package (`packages/math`).

**Spec:** `docs/superpowers/specs/2026-11-17-mhchem-design.md`

## Global Constraints

- PHP floor `^8.4`; run every suite on PHP 8.5 (`php`) and PHP 8.4 (`/opt/homebrew/opt/php@8.4/bin/php`), Xdebug off.
- The reader never throws and never does unbounded work: input length, nesting, cell count and macro limits cover `\ce` and `\pu`, including math inside them.
- The TeX writer writes only TeX that KaTeX accepts, plus `\ce{…}`/`\pu{…}` as read (KaTeX's mhchem extension).
- No chemistry node types. No hacks (negative spaces, phantoms) for prescripts.
- Fixtures are ordinary school and first-year university chemistry; no consumer-specific content.
- US English. Comments and docs name the actor, not the project. Docs follow the beautiful-prose rules: no em dashes, no filler.
- Notes: one per element and reason per formula (the reader's `note()` dedupe), level `approximated` for anything drawn differently, `dropped` for anything not drawn.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; no session links.

## Review Focus

1. **A second `\boxed` in one formula.** `note()` returns bare content for a repeated note, so source held on `Fallback` would be lost for the second box. Expect `\boxed{x}+\boxed{y}` to write back both boxes (Task 1 test).
2. **Macros inside a sourced construct.** `\newcommand\v{x}\boxed{\v}` must write `\boxed{x}`, not `\boxed{\v}` with the definition gone (Task 1 test).
3. **`-` as charge versus bond.** `\ce{Cl-}`, `\ce{NH4+}`, `\ce{CH3-CH3}`, `\ce{H-Cl}` and `\ce{e-}` must each get the right reading (Task 4 corpus).
4. **Malformed generated chemistry.** Unclosed `(`, `[`, `{`, a dangling `->[`, `^` at the end, empty `\ce{}`: draw what can be read, note the rest, never throw (Task 7 tests).
5. **`\ce` inside other constructs.** `\frac{\ce{H2O}}{2}`, `\text{…$\ce{O2}$…}`, `\ce` in an aligned cell, `\ce` inside `\boxed`: source nesting must still round-trip (Task 4 test).
